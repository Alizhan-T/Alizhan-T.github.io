# 3D-модель для интро

Положите сюда GLB-файл `m5_f90.glb` (модель с подходящей лицензией, например CC-BY/CC0 с Sketchfab,
или купленная/собственная). Необязательно: `studio.hdr` — HDRI для отражений.

- Если файл есть — сайт показывает 3D-интро (Three.js + GSAP): фары, силуэт, подлёт камеры, облёт, титул.
- Если файла нет — показывается видео-интро.
- Настройки (ось «перед» модели, длина, имена материалов фар, титул): `src/components/modelIntroConfig.ts`.
  Ось можно проверить без пересборки: `?front=-z`, `?front=+x`, `?front=-x`.
- Соблюдайте лицензию модели (указание автора в README/футере, если требуется).
- После добавления файла выполните `npm run build` — он скопирует `models/` в корень для GitHub Pages.
